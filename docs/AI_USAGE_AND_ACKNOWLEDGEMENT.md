# AI Usage and Acknowledgement

## 1. Purpose

This document records the AI tools and services used during the development of HarvestHub. AI was used mainly to assist with development, design, debugging, and some application features. The final implementation was reviewed and adapted as part of the project development process.

## 2. AI Tools and Services Used

### ChatGPT — OpenAI

ChatGPT was used during the development of HarvestHub to assist with different parts of the project.

It was mainly used for:

- Debugging Dart and Flutter errors
- Understanding compiler and analyzer messages
- Reviewing and restructuring project files
- Working through UI layouts and user interaction ideas
- Resolving issues between models, repositories, providers, and screens
- Getting guidance on Firebase and Firestore implementation
- Discussing project structure and documentation
- Explaining errors and suggesting possible solutions

The suggestions provided by ChatGPT were reviewed and adjusted to fit the actual HarvestHub project.

### OpenAI Image Generation

OpenAI image generation was used for visual design and asset ideas for HarvestHub.

It was used to help create and explore visual assets, including branding-related graphics and application visuals. The generated material was reviewed and adapted before being used in the project.

### Figma AI

Figma AI was used during the design stage of the application.

It helped with:

- UI design ideas
- Screen layout suggestions
- Visual organisation of application elements
- Exploring design variations for the HarvestHub interface

The final screen designs were adjusted to match the requirements and the design direction of the HarvestHub application.

### Gemini API

The Gemini API by google (gemini-3.1-flash-lite) was used as part of the Farm Products Assistant feature, called **Flora**, in the HarvestHub application.

Gemini is used to provide AI-generated responses to users' questions about farm products and related information. A predefined-response fallback is also included in the application so that the assistant can still provide basic responses when the Gemini API is unavailable or when an API key has not been configured.

Gemini is therefore part of the actual application functionality, while the other AI tools listed in this document were mainly used to support the development and design process.

## 3. Developer Responsibility

The project developer remains responsible for the final application and its implementation.

This includes:

- Understanding how the application works
- Reviewing and modifying AI-assisted suggestions
- Testing the application and correcting errors
- Making the final design and development decisions
- Understanding the Firebase, Firestore, Flutter, and Gemini implementation
- Preparing the project documentation
- Being able to explain the project during evaluation

## 4. AI Usage in the Project

AI was used as a support tool during development and not as a replacement for the we the developers' work. The application was built and adjusted based on the project's requirements, including the customer, farmer, and administrator modules.

The use of AI also helped with problem solving, especially when debugging development errors, exploring interface designs, and implementing the Flora assistant.

## 5. SRS Compliance Note

The HarvestHub SRS requires AI tools used during the project to be acknowledged in the project documentation or submission. It also states that AI should be used as a supporting aid and that the developer should understand and be able to explain the submitted work.

The tools and services used for HarvestHub have therefore been listed in this document for transparency.
